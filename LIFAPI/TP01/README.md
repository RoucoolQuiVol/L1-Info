# TP01 - C++ Exercises / Exercices C++

## 🇫🇷 Français

Ce dossier contient une collection d'exercices C++ de programmation introductifs réalisés en première année d'informatique. Les exercices couvrent les concepts fondamentaux comme les structures de contrôle, les opérateurs et la validation d'entrée.

### 📋 Contenu des fichiers

#### 1. **Calculatrice.cpp**
Un programme de calculatrice simple qui effectue des opérations arithmétiques de base.
- **Fonctionnalités** : Addition, Soustraction, Multiplication, Division
- **Points clés** : Utilisation d'un `switch` pour gérer les opérateurs, vérification de la division par zéro
- **Entrée** : Deux nombres entiers et un opérateur (+, -, *, /)

#### 2. **Calendrier.cpp**
Convertit un nombre de jours en semaines et jours.
- **Fonctionnalités** : Conversion de jours en semaines/jours
- **Points clés** : Boucle `do-while` pour valider une entrée positive, utilisation de la division euclidienne (/, %)
- **Entrée** : Un nombre entier strictement positif

#### 3. **Question Intervalle.cpp**
Valide qu'une valeur se trouve dans un intervalle donné.
- **Fonctionnalités** : Vérification des bornes, validation répétée
- **Points clés** : Gestion d'intervalle avec condition, boucle `while` pour la validation
- **Entrée** : Deux bornes et une valeur à vérifier

#### 4. **Question Minimum.cpp**
Trouve et affiche le minimum entre deux nombres réels.
- **Fonctionnalités** : Comparaison de deux nombres, gestion de l'égalité
- **Points clés** : Structure `if-else if-else` pour la comparaison
- **Entrée** : Deux nombres réels (float)

#### 5. **Question Moyenne.cpp**
Calcule la moyenne de deux nombres réels.
- **Fonctionnalités** : Calcul simple de moyenne
- **Points clés** : Opération arithmétique basique
- **Entrée** : Deux nombres réels

#### 6. **Table de multiplication.cpp**
Affiche la table de multiplication d'un nombre donné.
- **Fonctionnalités** : Boucle pour générer la table (0 à 10)
- **Points clés** : Boucle `for`, validation d'entrée avec `do-while`
- **Entrée** : Un nombre entier positif

## 🇬🇧 English

This folder contains a collection of introductory C++ programming exercises completed in the first year of computer science studies. The exercises cover fundamental concepts such as control structures, operators, and input validation.

### 📋 File Contents

#### 1. **Calculatrice.cpp** (Calculator)
A simple calculator program that performs basic arithmetic operations.
- **Features** : Addition, Subtraction, Multiplication, Division
- **Key Points** : Use of `switch` statement for operator handling, division by zero check
- **Input** : Two integers and an operator (+, -, *, /)

#### 2. **Calendrier.cpp** (Calendar)
Converts a number of days into weeks and days.
- **Features** : Conversion of days to weeks/days
- **Key Points** : `do-while` loop for positive input validation, use of integer division (/, %)
- **Input** : A strictly positive integer

#### 3. **Question Intervalle.cpp** (Range Validation)
Validates that a value falls within a given interval.
- **Features** : Bounds checking, repeated validation
- **Key Points** : Range handling with conditions, `while` loop for validation
- **Input** : Two bounds and a value to verify

#### 4. **Question Minimum.cpp** (Minimum)
Finds and displays the minimum between two real numbers.
- **Features** : Comparison of two numbers, equality handling
- **Key Points** : `if-else if-else` structure for comparison
- **Input** : Two real numbers (float)

#### 5. **Question Moyenne.cpp** (Average)
Calculates the average of two real numbers.
- **Features** : Simple average calculation
- **Key Points** : Basic arithmetic operation
- **Input** : Two real numbers

#### 6. **Table de multiplication.cpp** (Multiplication Table)
Displays the multiplication table for a given number.
- **Features** : Loop to generate table (0 to 10)
- **Key Points** : `for` loop, input validation with `do-while`
- **Input** : A positive integer

## 🎓 Learning Objectives / Objectifs d'apprentissage

- **Structures de contrôle / Control Structures** : `if`, `else`, `switch`, `while`, `do-while`, `for`
- **Opérateurs / Operators** : Arithmetic, comparison, logical operators
- **Validation d'entrée / Input Validation** : Ensuring user input meets requirements
- **Entrée/Sortie / Input/Output** : Using `cin` and `cout` for console operations
